# World Forge 1.0.0

Deterministic multi-tile terrain, texturing, spawning and POI tool for Unity 6 (URP), with an integer core-map export for engine-free simulations.

- Start: **Tools ▸ World Forge ▸ World Designer** (or *Create Ashen Krypt Sample World*).
- German docs: `Documentation/Schnellstart-DE.md`, `Documentation/Integration-DE.md`.
- Tests: Test Runner ▸ EditMode ▸ `AshenCrypt.WorldForge.Tests`.
