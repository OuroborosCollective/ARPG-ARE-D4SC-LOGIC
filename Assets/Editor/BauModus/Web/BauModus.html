Bau-Modus

Zugangsschlüssel aus dem Unity-Fenster Fadenwerk → Einstellungen eingeben (oder über den geschützten Link öffnen).

So baust du

  1. Gebiet wählen (oben links). Unity zeigt das Gebiet sofort im Editor; die Karte hier ist ein echtes Bild aus Unity.
  2. Auf eine freie Stelle tippen → Baumenü. Oder unten eine Kategorie wählen (Häuser, Props, Bewohner, Natur, Untergründe …).
  3. Das Teil erscheint als Vorschau (grüner Rahmen) – hier und gleichzeitig in Unity. Ziehen zum Verschieben, ⟲ ⟳ zum Drehen, − + für die Größe.
  4. ✓ Bauen übernimmt es fest: Unity speichert den Bauplan und zeigt das Teil live – im Editor und, wenn das Spiel läuft, direkt im Spiel.
  5. Gebautes antippen → verschieben, drehen, kopieren oder abreißen. ↶ macht den letzten Schritt rückgängig.
  6. Untergründe: Fläche mit dem Finger aufziehen. Wald-Pinsel: Kreis setzen, Radius/Anzahl wählen, pflanzen.

Farben: grün = passt, orange = überlappt (erlaubt), rot = außerhalb des Baugebiets.

Tasten: Q/E drehen · Enter bauen · Esc abbrechen · Entf abreißen · Strg+Z rückgängig · Pfeile verschieben die Ansicht · +/− Zoom · R Ansicht drehen.

Gespeichert wird in Assets/Resources/ARE/BuildLayouts/<gebiet>.json. Das Spiel lädt diese Datei selbst – auch in der APK nach dem nächsten Build.
