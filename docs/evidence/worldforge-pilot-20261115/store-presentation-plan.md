Editor. The map integration passed real Core checks over 200 routes and a native
map EditMode check. Generation-only timings are recorded; no percentage
productivity gain, Android performance or complete commercial readiness follows.

The authoring run skipped terrain texturing because no texture rules were assigned.
The game projection uses its existing ground material. Do not advertise this run
as proof of a complete independently textured standalone sample.
