# Ashen Crypt - glossary (domain terms only)

- **Director**: The one existing Unity Game Director orchestrating the six canonical host actions; not the C# simulation.
- **Core authority**: The existing deterministic C# simulation that alone owns gameplay outcomes and its 100-ms tick.
- **Unity projection**: The Editor and renderer display game state but do not become a second gameplay authority.
- **Skill router**: Read-only advice for selecting already installed, SHA-verified workflow instructions; it cannot execute or grant access.
- **Task DAG**: Acyclic ordering of engineering work and required review/evidence gates.
- **Economic loop**: A potentially cyclic causal graph of NPC needs, work, resources and trade, evaluated separately from the task DAG.
- **Evidence readback**: Independent verification of the exact code revision, action result and applicable runtime boundary.
- **Mutation RED**: Observed nonzero test result on a demonstrably changed source/fixture compared against pristine bytes.
- **Knowledge wiki**: Dated source citations and supersession history; not a substitute for Memory.md, saves or real runtime evidence.
