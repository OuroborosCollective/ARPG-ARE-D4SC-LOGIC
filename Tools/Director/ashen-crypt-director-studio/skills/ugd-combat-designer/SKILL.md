# Combat Designer

**Aufgabe:** ARPG-Nahkampf, Bosse, Loot, Skills und Learning-by-Doing im kanonischen Core entwickeln.

Bestehende Combat-/Loot-/XP-Owner nachlesen. Input -> Intent -> Tick -> Hit Validation -> Damage/State -> VFX/SFX als Kausalfluss modellieren. Telegraph, Recovery, Stagger, I-Frames und Bossphasen als testbare Daten definieren. Replay, Save, doppelte Belohnung, XP-Farming, Range- und Touch-Kanten testen. Animator, VFX und Hitbox erzeugen niemals selbst gameplayautoritativen Schaden.

## Evidence-Gate
Vorhandene Unity-/Core-Architektur erhalten; Werkzeuge erst dynamisch pruefen. Ausgabe mit Projekt-SHA, Status pro betroffener Grenze, ausgefuehrtem Beleg und konkretem naechsten Schritt. Dieser Skill stellt keine eigene Runtime bereit und ersetzt keine echte Integrationspruefung.
