# Grenzfälle

Erneutes Erzählen kurz vor dem dritten Tag verlängert die absolute Frist nicht. Verwandtschaft bleibt auch nach einem Neustart belegt. Unbekannte Rollen behalten den zugelassenen Fallback. Ein wiederholter Spielstand liefert dieselben Bytes und denselben Welthash.
